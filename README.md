# 百人一首 自動読み上げシステム

ブラウザの Web Speech API を使って、百人一首を自動で読み上げる静的 Web アプリです。

## 使い方

1. `index.html` をブラウザで開きます。
2. 札一覧をクリックして、その回のゲームに入れる歌を選びます。
3. 必要に応じて、読み上げ速度・読み上げ間隔・読み順を調整します。
4. 「開始」を押すと、選択した歌を自動で読み上げます。

## 機能

- 100首からクリックでゲーム対象の歌を選択・解除
- 全選択、全解除、ランダム20首選択
- 番号・作者・歌本文の検索
- ランダム順または歌番号順の読み上げ
- 読み上げ速度と次の歌までの間隔調整
